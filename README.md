# 玥玥练习

这是一个浏览器里的小学算术练习游戏。每解一道题，画面演出和音乐都会越来越热闹。

毛绒绒兔子吉祥物“玥玥”会搬运你输入的数字，答对后为你庆祝。随着题目推进，画面和声音会不断增加，最后像进入热闹的祭典一样。答错也不会让气氛降下来，也没有游戏失败。

## 特点

- 面向小学 1～6 年级的 58 个计算技能，覆盖加法、减法、乘法、除法、竖式中间步骤、小数、分数、百分比、比例等内容
- “我的水平”模式：先通过能力检查确定起点，再根据熟练度逐步解锁后续技能
- 支持按年级模式、练习、复习、技能树、任务、奖杯、收藏和日历记录
- 基础题全做完为 100 分。首次正确率达到 80% 以上时，可以进入限时 EXTRA 挑战更高分
- 音乐和音效全部由 Web Audio API 合成，不使用音频文件
- 支持手机竖屏和 PC；PC 上可以用数字键和 Backspace 输入
- 可在设置中调节动效强度、音量和静音
- 记录全部保存在本机浏览器的 localStorage 中，不会发送到外部

## 本地游玩

不需要构建。只要把 `app/` 作为静态文件目录提供 HTTP 服务即可。

```bash
python3 -m http.server 8000 -d app
```

然后在浏览器打开 `http://localhost:8000/`。项目使用 ES Modules，因此不能直接用 `file://` 打开。

## 测试

需要 Node.js 20 或更高版本。

```bash
node --test tests/*.test.mjs
```

## 目录结构

| `docs/curriculum.md` | 年级课程和技能树设计 |
| `docs/dopakichi.svg` | 玥玥兔子造型原稿 |
| `tests/` | 单元测试 |
| `tools/build_fonts.sh` | 重新生成字体子集的工具，增加界面文字后可运行 |
