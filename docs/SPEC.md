# 玥玥练习公开版规格说明

玥玥练习是一个浏览器算术练习游戏。玩家每完成一道计算题，毛绒绒兔子吉祥物的动作、画面演出和音乐都会增强。本文面向玩家、家长以及想了解或改造项目的人，说明当前实现的行为。数值以后可能调整。

## 1. 设计目标

游戏希望让孩子每天持续练习计算，并能看见自己比过去进步。基础题即使超过目标时间也可以继续，全部完成就是 100 分，没有游戏失败。

答错时界面显示“再试”，玩家可以继续输入。已经得到的星星、奖杯、收藏和演出不会因为失败或缺席被收回。连续记录可以用免断签锤补回缺席日；成长对比只展示有进步的项目。奖励只由条件达成解锁，不含抽奖或付费获取。

## 2. 画面

| 画面 | 内容和主要操作 |
| --- | --- |
| 标题 | 标志、玥玥、我的水平、复习、1～6 年级、技能树、奖杯、收藏、今日任务、日历、设置、玩法说明 |
| 答题 | 题目、输入格、数字键盘、正确数、再试次数、计时、玥玥、连击、进度、静音 |
| 基础结果 | 100 分、用时、首次正确率、玥玥、成长/技能/任务结果，以及 EXTRA、复习、再玩、返回标题 |
| 最终结果 | 含 EXTRA 的总分、玥玥、正确数、再试次数、任务、复习和返回标题 |
| 技能树 | 前置关系、解锁/练习/掌握状态、星级、生疏状态、技能详情、练习、删除记录 |
| 奖杯 | 分类和系列成就、获得日期、条件、奖励、筛选、快达成项目 |
| 收藏 | 已解锁演出的预览/试听，按类别固定或随机 |
| 设置 | 题目数量、声音、音量、动效强度、演示、全部数据重置 |

通常流程是“标题 → 基础题 → 基础结果 → 可选 EXTRA → 最终结果”。复习只到基础结果。

## 3. 模式

### 我的水平

首次为能力检查。系统按年级和前置深度排列技能，跳跃式出题。某题首次答对时，会把该技能及其前置技能一起标为已掌握并给 ☆1。检查完成后，系统会根据解锁但未掌握的前沿技能、已掌握技能中的复习候选和生疏技能来混合出题。

### 按年级

无论技能是否已解锁，都从所选年级的技能中出基础题。题目大致按前置关系由浅到深，并加入随机扰动。EXTRA 前 6 题使用该年级后半技能，第 7 题起切到下一年级的开头技能；6 年级则继续使用本年级后半技能。

### 练习

从技能树选择已解锁技能进行专项练习。已掌握技能也可从技能详情进入练习。基础题使用该技能，EXTRA 使用以该技能为直接前置的已解锁技能；没有候选时继续同一技能。

### 复习

含再试的题目会保存为错题，最多 40 题。题目标题和式子作为去重依据，未完成就中断的题目不会保存。标题和结果页都可以进入复习。首次答对的复习题会从列表删除；再次答错则保留。复习没有 EXTRA。

### 演示

设置中的“观看自动演示”会自动游玩一轮，不写入历史、熟练度、复习、成长统计、任务或奖杯。点击画面或按键可结束。

## 4. 答题和输入

题目数量可选 6、10、14，默认 10。基础目标时间按题量计算，超时不扣分。基础首次正确率达到 80% 以上即可进入 90 秒 EXTRA。

玩家用屏幕数字键盘或电脑数字键逐位输入，不需要提交按钮。正确位会保留，错误数字会被下一次输入替换。Backspace 只删除当前错误数字，不撤销已答对的位。

| 题型 | 输入顺序 |
| --- | --- |
| 横式 | 从答案左侧开始 |
| 带余数除法横式 | 商，然后余数 |
| 加减竖式 | 从最低位开始，进位/退位辅助数字自动显示 |
| 乘法竖式 | 部分积从右侧开始，多个部分积时合计也从右侧开始 |
| 除法竖式 | 商、减完的余数、下一个商；乘积、下落数字和末尾 0 自动显示 |
| 小数 | 小数点自动显示，只输入数字 |
| 分数 | 分母、分子；带分数先输入整数部分 |
| 比、字母式、概数、百分比 | 从指定空格左侧开始 |

同一格多次答错时，界面会高亮参考数字并显示提示。提示可能包含中间式、乘法表、通分分母等。

## 5. 得分、玥玥和连击

基础题完成固定 100 分。EXTRA 中第 `k` 道已完成题的加分为 `10 + 5 × k`，没有固定上限。

玥玥是演出数值，与得分分开。内部以常用对数 `L` 保存，显示值来自 `10^L`。正确输入会提高玥玥；连击越高，提高越快，20 连击及以上达到 `玥玥×2 MAX`。答错会清空连击，但不降低得分、玥玥或演出阶段。

## 6. 技能、星级和生疏

普通掌握条件是至少做过 6 题，并且最近 6 题里有 5 题首次正确。所有前置技能掌握后，后续技能解锁。掌握不会因为一次答错而失去。

掌握后继续练习可以升星。星级条件包括最近正确率、速度、间隔天数后的连续首次正确，以及高正确率和速度的综合条件。生疏技能会优先进入复习；首次答对 1 题后会被打磨为正常状态。

## 7. 记录、任务、奖杯和收藏

记录保存在本机 localStorage 中。日历显示每日游玩次数、最高分、连续天数、贴纸和免断签锤。

今日任务由日期和当前能力决定，通常包含两个容易任务和一个稍难任务，目标约 15 分钟内可完成。当天全部完成后可获得免断签锤，数量有上限。

奖杯按系列和分类展示，条件固定、非随机。奖杯可以解锁背景、正确标记、彩纸、音乐、换装、颜色、观众和结尾演出等收藏项。收藏可以固定选择，也可以设为“随机”。

## 8. 数据和隐私

所有记录、设置、进度、奖杯、收藏和错题都保存在当前浏览器，不需要账号，也不会自动同步到其他设备。全部重置会删除带有项目前缀的保存数据。
